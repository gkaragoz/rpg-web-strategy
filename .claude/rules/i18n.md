# UI text and languages

- Every user-visible string goes through `t('area.key', { vars })` from `src/i18n.ts`; the tables are `src/i18n/{studio,battle,maps,units,online,system}.ts`, each with `en` and `tr`. Add the key to **both** languages (same placeholders). `src/sim/__tests__/i18n.test.ts` fails otherwise.
- English is the default; Turkish text must be correct Turkish (with diacritics). Never hard-code Turkish or English UI strings in components.
- Localized data uses `Localized { en, tr }` + `loc()` (roster skill texts, map presets); display names of the five classic units go through `unitDisplayName()`.
- The network carries **codes**, not texts (placement failures, close reasons, action labels). The receiver translates (`online.reason.*`, `online.act.*`).
- Strings are built once; changing the language reloads the page (`switchLang`). Do not cache translated text across a language switch.
- Comments, identifiers and commit messages are English.
